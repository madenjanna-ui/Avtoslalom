# MaDen AutoSlalom v5

Новая визуальная концепция по референсу пользователя:
- вертикальный экран;
- 4 полосы;
- спортивная машина игрока крупным планом;
- машины навстречу;
- грузовики;
- конусы и барьеры;
- перспективная трасса;
- день / ночь / дождь;
- фары и мокрый асфальт;
- конусы дают урон, 3 конуса = авария;
- тяжёлое препятствие/машина = авария;
- аварийная пауза 1.5 сек, тряска, вспышка, частицы и вибрация;
- очки и рекорд;
- 3 сложности.

Это высококачественный 2.5D Canvas-прототип без внешних библиотек. Для действительно фотореалистичной 3D-графики следующей ступенью будет WebGL/Three.js с моделями автомобилей и трассы.
