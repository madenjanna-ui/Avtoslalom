- более детализированная спортивная машина;
- конусы не снимают попытку: каждый конус = 1 уровень урона;
- 3 конуса = авария и потеря одной попытки;
- тяжёлое препятствие = немедленная авария;
- отдельные автомобильные аудиотреки: двигатель, дорога, дождь, удар;
- вибрация;
- день / ночь / дождь;
- ночные фары и видимость препятствий;
- мокрая дорога, лужи и занос;
- PWA manifest и иконка приложения.
