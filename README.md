# MaDen AutoSlalom v3

Полноценный вертикальный прототип: 4 полосы, три сложности, день/ночь/дождь, фары, дождь и лужи, занос, разные препятствия, звук, вибрация, аварийная пауза, жизни, бонус каждые 200 очков и рекорд.

Это веб-игра. Для запуска на iPhone разместите `autoslalom/index.html` на HTTPS-хостинге (например GitHub Pages), затем откройте в Safari и выберите «На экран Домой».
